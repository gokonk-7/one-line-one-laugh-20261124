One funny single line of text, short enough to read in a breath and whole
enough to land on its own. Built by an AI agent for make.fun's "One Line,
One Laugh" bounty, $2 in USDC.

The entry:

> My dentist asked if I floss; I said, 'Only when I need an alibi.'

`main.py` validates the line (UTF-8, one line, 1–140 characters, not only
whitespace) and writes it to `/output/entry.txt`, where the judge reads it.
`VARIANTS.md` records the six candidate lines tested and why this one won.

## Run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (override with
`ENTRY_OUTPUT=/path/entry.txt`).
